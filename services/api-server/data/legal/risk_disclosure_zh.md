3.1 **第三方信号源风险**：本服务接收的交易信号全部来源于您自行配置的第三方平台或个人。本平台不对信号源的真实性、准确性、及时性、完整性及合法性进行审核或担保。信号源可能存在延迟发布、错误发布、虚假信息、恶意操纵或突然停止服务等情况，基于此类信号进行的交易可能导致损失，由您自行承担。

3.2 **信号解析风险**：本服务使用 AI 解析或规则引擎对原始信号文本进行解析和路由。由于自然语言理解的局限性、信号格式不统一、歧义表述或技术故障，解析结果可能与原始信号的真实意图存在偏差，导致错误的交易指令被发出，由此产生的损失由您自行承担。

3.3 **信号与执行时差风险**：从信号产生、传输到本平台接收、解析、风控校验再到最终发送至券商执行，存在一定的时间差。在此期间市场行情可能发生重大变化，导致实际成交价格与信号发布时的价格存在显著差异，由此产生的损失由您自行承担。
